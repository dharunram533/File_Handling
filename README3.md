## Problem
Write a C program to append employee details to an existing file without overwriting the previous records

## Algorithm
1.Start.
2.Open the file student1.txt in append ("a") mode.
3.Write the text "Favorite colour: Blue & Green" at the end of the file using fprintf().
4.Close the file using fclose().
5.Stop

## Sample output
Name:Dharun Ram P
Rollno:210
Marks:100
Favorite colour:Blue & Green
