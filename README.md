##  Problem
Write a C program to create a text file named student.txt and write the student's Name, Roll Number, and 
Marks into it using user-defined functions.

##  Algorithm
1.Start.
2.Open the file student1.txt in write ("w") mode.
3.Write the student's name, roll number, and marks into the file using fprintf().
4.Close the file using fclose().
5.Stop.

## Sample output
Name:Dharun ram P Rollno:210 Marks:100(in student.txt)
